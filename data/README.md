# Data

`raw/` holds the English files of the Mandarine Academy Recommender System (MARS) dataset, exactly as
downloaded from Harvard Dataverse:

| File | Contents |
|---|---|
| `explicit_ratings_en.csv` | Watch events: learner, video, watch percentage, a "rating" (the watch percentage rescaled to 1-10) and a timestamp |
| `implicit_ratings_en.csv` | Page views: learner, video and timestamp |
| `items_en.csv` | Videos: title, subtitles (in the description column), type, tags, duration and view count |
| `users_en.csv` | Learners: an anonymised ID and an optional job |

The dataset is released under the CC0 1.0 licence, which is why I can include it here.

Source: Hafsa, M. (2022) *E-learning Recommender System Dataset*, version 2.0. Harvard Dataverse.
https://doi.org/10.7910/DVN/BMY3UD

Described in: Hafsa, M., Wattebled, P., Jacques, J. and Jourdan, L. (2023) 'E-learning recommender system
dataset', *Data in Brief*, 47, 108942. https://doi.org/10.1016/j.dib.2023.108942
